# Exchange field values with FDF

`form.values_fdf()` exports supported present values as deterministic FDF 1.2; `template.values_from_fdf(bytes)` converts a values-only FDF into typed assignments for `fill` or `fill_batch`. Exported field hierarchy uses T/Kids dictionaries. Text and choice values are strings, buttons use actual PDF export names, and multi-selections use arrays. Absent values are omitted. Read-only values may be exported, but importing into read-only targets is refused.

The input profile is strict classic-xref FDF 1.2 within 1 MiB, 4096 field nodes and depth below 64. It accepts only Root/Size trailer entries, a catalog containing FDF, an FDF dictionary containing Fields, and field T/V/Kids entries. Unsupported attributes, annotations, appearances, actions, external-file references, encryption, incremental trailers, unknown names, duplicate assignments, invalid types and cycles are rejected. Radio Off assignments require the reset workflow. This is value exchange, not preservation of every FDF feature; no unsupported attributes are silently stripped.

Run `formferry export-fdf COMPLETED.pdf NEW.fdf`, then `formferry fill-fdf TEMPLATE.pdf NEW.fdf NEW.pdf` through `moon run bin/formferry --target wasm -- ...`. Filling verifies every imported value before publication and supports trailing `--fit-text`. Layout and choice membership are checked by fill, not inferred by the FDF decoder. Existing outputs are refused. `moon run samples/verify.mbtx wasm` exports a filled three-page sample, fills a fresh template, and checks byte-identical PDF output.

PDF syntax, classic-xref IO and object writing reuse the existing Apache-2.0 pdflite dependency. The FDF header is replaced at equal length so offsets remain unchanged. Semantic reference: [Adobe Forms overview](https://opensource.adobe.com/dc-acrobat-sdk-docs/library/overview/Overview_Forms.html) and its PDF reference's Forms Data Format section. No upstream FDF implementation or fixtures copied. Acrobat/other-tool interoperability has not been independently certified; tests validate the documented subset and authored fixtures.
